## Overview

Tags are simple labels you attach to contacts — like `VIP`, `Trial`, or
`Newsletter`. Use them to filter the contacts list, build [segments](/contacts/segments),
and target campaigns. A contact can have any number of tags.

<Info>
  **Where to manage them:** **CRM → Audience → Tags** in the sidebar (`/tags`)
  &nbsp;·&nbsp; **Difficulty:** Beginner
</Info>

<Note>
  Tags moved out of Settings. Old links to `/settings/tags` redirect to the new
  **Tags** page.
</Note>

## Manage tags

<Steps>
  <Step title="Open the Tags page">
    Go to **CRM → Audience → Tags** in the sidebar.
  </Step>
  <Step title="Create a tag">
    Type a name in the **Search tags, or type a new name to add...** box (up to 50
    characters) and click **Add** or press Enter. If a tag with that name already
    exists, the button stays disabled. The same box filters the list as you type.

  <Step title="Rename or delete">
    Click **Edit tag** (pencil) to rename a tag inline — press Enter to save or

  </Step>

<Note>
  Tag **colors are assigned automatically** from the tag name, so tags stay visually
  consistent. There's no manual color picker; renaming a tag refreshes its color.
</Note>

## Assign tags to contacts

You can add tags in several places:

- **On a contact** — in the create/edit dialog, or the **Tags** section of the
  contact detail page. Start typing to search existing tags or create a new one on
  the fly.
- **In bulk from the contacts list** — select contacts, open **Bulk Actions**, and
  choose **Assign Tags**. Duplicate assignments are skipped automatically.
- **During CSV import** — apply tags to every imported contact in the **Tags &
  Options** step. See [Import contacts](/contacts/import-csv).

## Use tags to target contacts

- **Filter** the contacts list, then act on the results.
- **Build a segment** with a "Has tag" rule for automatic, always-current audiences
  — see [Segments](/contacts/segments).

## FAQ

<AccordionGroup>
  <Accordion title="Can I set a tag's color?">
    Not manually — Autocampaign AI derives a consistent color from the tag's name.
  </Accordion>
  <Accordion title="What happens when I delete a tag?">
    It's removed from all contacts, and from any join links, SMS templates, tickets,
    opportunities, or lead forms that used it. This is permanent, so delete with
    care.
  </Accordion>
  <Accordion title="How are tags different from segments?">
    A tag is a manual label you attach. A [segment](/contacts/segments) is a group —
    it can be static (manually managed) or dynamic (auto-updated from rules, which
    can include tags).
  </Accordion>
  <Accordion title="Can I bulk-apply a tag to many contacts at once?">
    Yes. Select contacts in the list, open **Bulk Actions → Assign Tags**, pick the
    tags, and click **Apply Tags**. You can also apply tags to every row during
    [CSV import](/contacts/import-csv).
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="I can't add a tag — the Add button is disabled">
    A tag with that exact name already exists, or the name is empty or over 50
    characters. Adjust the name. Tag names are case-sensitive, so "VIP" and "vip"
    are treated as different tags — search, however, ignores case.
  </Accordion>
</AccordionGroup>
