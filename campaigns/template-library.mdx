## Overview

The Template Library is a curated catalog of ready-made starters maintained by
Autocampaign AI. Instead of writing every message from scratch, pick a template that
matches your industry and goal, preview it, and add it to your workspace as an
editable copy or a prefilled draft. Find it under **Marketing → Campaigns →
Templates** on the **Library** tab (`/templates/library`).

<Info>
  **Difficulty:** Beginner &nbsp;·&nbsp; The library is the default tab when you open
  **Templates**, as long as you have permission to view it.
</Info>

The catalog holds about 70 curated entries across seven template types:

| Type badge | What you get when you use it |
| --- | --- |
| **Text message** | A message body opened in the Inbox composer, ready to send |
| **Email** | An editable copy in **Templates → Email**, opened in the builder |
| **SMS Campaign** / **Email Campaign** | The new-campaign wizard prefilled with name, channel, and content |
| **Sequence** | A new sequence with its steps, opened in the sequence editor |
| **Form** | A new lead form, opened in the form editor |
| **Automation** | A new workflow, opened in the workflow builder |
| **AI Employee** | The new AI Employee wizard with the job preselected |

## Before you start

- The library shows every entry, but using one requires permission to **create**
  that type of asset (campaigns, email templates, sequences, forms, workflows, or
  AI Employees). Ask an admin if **Use this template** fails with a permission error.
- Library entries are system-owned. You can't edit the catalog itself — you edit the
  copy that lands in your workspace.

## Find a template

<Steps>
  <Step title="Pick a type" icon="table-cells">
    Use the type rail at the top — **All**, **Text message**, **Email**,
    **Automation**, **Sequence**, **Form**, **Campaign**, **AI Employee** — to narrow
    the grid.
  </Step>
  <Step title="Search and filter" icon="filter">
    Type in **Search templates...** or open **Filters** to combine:

    - **Category** — appears once you pick a type; options depend on it, for example
      Promotions, Reminders, Reviews, Re-engagement, Welcome, Orders, or Seasonal for
      text messages.
    - **Channel** — Text or Email.
    - **Industry** — Healthcare, Real estate, Home services, Restaurant, Retail,
      Fitness & beauty, or General.
    - **Goal** — Lead generation, Promotions, Reminders, Reviews & referrals,
      Retention, Onboarding, or Transactional.
    - **Level** — Beginner, Intermediate, or Advanced.

    Toggle **Favorites only** to see templates you've starred, and change **Sort:**
    between **Popular**, **Newest**, and **A–Z**. Each filter takes one value, and
    search matches template names and descriptions only. Filters are kept in the page
    URL, so you can share a filtered view with a teammate. Click **Clear all** to
    reset.

## Preview and use a template

<Steps>
  <Step title="Open the preview" icon="eye">
    Click a card to open the **Template preview** drawer. What you see depends on the
    type: the **Message** body for text and SMS campaigns, the **Subject** and rendered
    design for email, **Setup steps** for sequences and automations, the question list
    for forms, and the persona summary with **About N min to set up** for AI
    Employees.

  </Step>
  <Step title="Add it to your workspace" icon="plus">
    Click **Use this template** (for email entries the button reads **Edit
    template**). It shows **Adding...** while the copy is created, then a **Template
    added** toast confirms and Autocampaign AI takes you straight to the result — the
    builder, editor, wizard, or Inbox composer listed in the table above.
  </Step>
  <Step title="Customize" icon="pen">
    Everything the library creates is yours to change. Edit the email design in the
    builder, adjust sequence steps and delays, rename the form, or rewrite the
    campaign message before you launch. Text and campaign templates already include
    merge tags such as `{{first_name}}` and `{{organization_name}}` — see
    [Templates](/campaigns/templates) for the full list.
  </Step>
</Steps>

<Note>
  Campaign and text-message templates don't create a saved record on their own. A
  campaign template prefills the new-campaign wizard as an unsaved draft, and a text
  template opens the Inbox composer — finish the wizard or send the message to keep
  the content. Email, sequence, form, and automation templates create a saved asset
  immediately.
</Note>

## What each type creates

- **Email** — a duplicate of the system email template, named after the library
  entry and saved as a draft in **Templates → Email**. Publish it to use it in
  campaigns. See [Templates](/campaigns/templates).
- **SMS Campaign** / **Email Campaign** — the campaign wizard opens with the name,
  channel, message body (SMS) or designed template, subject, and preview text (email)
  filled in. Pick your audience and sender, then schedule. See
  [Campaigns](/campaigns/overview).
- **Sequence** — a new multi-step sequence built from the template's steps. See
  [Sequences](/campaigns/sequences).
- **Form** — a new lead form using the template's questions. See
  [Lead forms](/growth/lead-forms).
- **Automation** — a new workflow from the template's trigger and steps. See
  [Workflow builder](/automation/workflow-builder).
- **AI Employee** — the AI Employee setup wizard with the matching job template
  selected. See [AI Employees](/automation/ai-employees).

## FAQ

<AccordionGroup>
  <Accordion title="Does using a template count against my plan?">
    The library itself is free to browse. The asset it creates counts like any
    other asset of that type — for example, an installed email template is one more
    email template in your workspace.
  </Accordion>
  <Accordion title="Can I use the same template twice?">
    Yes. Each use creates a fresh copy or a fresh prefilled draft. Rename the copy so
    you can tell them apart.
  </Accordion>
  <Accordion title="Can I add my own templates to the library?">
    No. The Library tab is a platform-wide catalog. Save your own reusable content
    under the **SMS**, **Email**, and **WhatsApp** tabs instead.
  </Accordion>
  <Accordion title="Why does the library show fewer results than expected?">
    Category options change with the selected type, and search matches the template
    name and description only. Click **Clear all** and try a broader filter.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="I can't see the Library tab">
    Your role lacks permission to read the marketplace. Ask a workspace admin to
    grant it. See [Users and roles](/getting-started/users-roles).
  </Accordion>
  <Accordion title="'Use this template' fails">
    You need permission to create that asset type — for example, campaign creation
    for a campaign template or workflow creation for an automation. Adding an
    entry also fails if your plan's limit for that asset type is reached.
  </Accordion>
  <Accordion title="The email opened in the builder but isn't in my campaign picker">
    Library email templates arrive as **Draft**. Choose **Publish** from the
    template's menu in **Templates → Email** to make it **Active**.
  </Accordion>
</AccordionGroup>
